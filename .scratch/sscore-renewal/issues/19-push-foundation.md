# 19: 푸시 기반: 기기 등록 + 발송 모듈

**What to build:** 앱이 FCM 기기 토큰을 서버에 등록하고 서버가 특정 회원에게 푸시를 보낼 수 있다. 로그아웃·탈퇴 시 그 기기의 토큰이 해제되어 알림이 가지 않는다. 푸시 발송은 가짜로 교체할 수 있다.

**Blocked by:** 04 로그인 + 로그인 유지 + 게스트 진입

**Status:** ready-for-agent

- [x] 로그인한 기기의 FCM 토큰이 서버에 등록되고 갱신된다
- [x] 로그아웃하면 이 기기 토큰이 해제된다
- [x] 탈퇴(유예 포함)하면 모든 기기 토큰이 해제된다
- [x] 한 회원의 여러 기기에 푸시가 간다
- [x] 푸시 발송이 포트로 분리되어 테스트에서 가짜로 교체되고 나간 푸시를 검증할 수 있다
- [x] 앱이 알림 권한을 요청하고 알림을 받는다
- [x] Firebase 프로젝트 설정 방법이 문서화된다
