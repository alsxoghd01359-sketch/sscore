# 13: 라이브 스코어 갱신

**What to build:** 사용자가 진행 중인 경기의 스코어와 경기 시간이 자동으로 갱신되는 것을 본다. 서버는 라이브 경기가 있을 때만 약 15초 간격으로 외부 API를 호출하고, 앱은 화면을 보는 동안 10~15초마다 새로 읽는다.

**Blocked by:** 08 서버 정리: 오류 응답, 현재 시즌 자동 결정, 컨트롤러 정리

**Status:** ready-for-agent

- [ ] 라이브 경기가 있을 때만 서버 스케줄러가 약 15초 간격으로 외부 API를 호출한다
- [ ] 라이브 경기가 없으면 외부 호출을 하지 않는다
- [ ] 스코어·경기 시간 등 바뀐 경기만 DB에 갱신된다
- [ ] 앱 홈 경기 목록이 화면이 보이는 동안 10~15초마다 새로 읽고 화면을 벗어나면 멈춘다
- [ ] 외부 API 오류 시 서버가 죽지 않고 다음 주기에 재시도한다
- [ ] 남은 호출량을 확인할 수 있는 로그가 남는다
- [ ] 가짜 외부 API와 주입된 시계로 호출 여부·갱신이 REST API 경계 테스트에서 검증된다
