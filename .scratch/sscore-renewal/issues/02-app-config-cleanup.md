# 02: 앱 서버 주소 분리 + 템플릿 잔재 정리

**What to build:** 개발자가 에뮬레이터와 실기기에서 서로 다른 서버 주소로 앱을 빌드할 수 있다. 평문 통신 허용은 개발 빌드에만 남고, 앱 이름과 테마 이름 등 템플릿 잔재와 중복 의존성이 정리된다.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [x] 서버 주소가 빌드 종류(개발/릴리스)별로 설정에서 분리되고 코드에 IP가 박혀 있지 않다
- [x] 평문 통신 허용이 개발 빌드에만 적용된다
- [x] 앱 이름·테마 이름이 서비스 이름으로 정리된다
- [x] 중복된 의존성 선언과 동작하지 않는 설정(Glide 어노테이션 처리 등)이 정리된다
- [x] 사용하지 않는 예제 코드(템플릿 테스트, 미사용 UserRequest)가 제거된다 (dataBinding은 레이아웃 8개가 <layout> 래퍼로 실제 사용 중이라 유지)
- [x] 디버그 빌드가 성공한다
