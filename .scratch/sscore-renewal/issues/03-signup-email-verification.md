# 03: 가입 + 이메일 인증코드

**What to build:** 신규 사용자가 이메일·비밀번호·닉네임으로 가입을 시작하고, 메일로 받은 6자리 인증코드를 앱에서 입력해 회원이 된다. 인증을 마치기 전에는 회원이 아니다.

**Blocked by:** 01 Flyway 기준선 + API 테스트 틀

**Status:** ready-for-agent

- [x] 가입 요청 시 입력한 이메일로 6자리 인증코드가 발송된다
- [x] 코드는 10분 후 만료되고, 만료된 코드는 거절된다
- [x] 재발송과 입력 실패 횟수에 제한이 있고 초과 시 거절된다
- [x] 올바른 코드를 입력하면 회원이 생성된다. 인증 전에는 로그인할 수 없다
- [x] 이미 가입된 이메일은 거절된다
- [x] 비밀번호는 8~20자+특수문자 규칙을 지키며 BCrypt로 해시되어 저장된다
- [x] 닉네임은 2~12자(한글·영문·숫자)이고 중복이 거절된다(DB 유일성 포함)
- [x] 가입 화면에서 규칙 안내와 코드 입력·재발송이 동작한다
- [x] REST API 경계 테스트와 가짜 메일로 위 동작이 검증된다
