# 06: 비밀번호 재설정·변경 + 닉네임 변경

**What to build:** 회원이 비밀번호를 잊으면 인증코드로 재설정하고, 로그인 상태에서는 현재 비밀번호를 확인한 뒤 변경하며, 닉네임을 바꿀 수 있다. 비밀번호를 바꾸면 다른 기기의 로그인이 풀린다.

**Blocked by:** 04 로그인 + 로그인 유지 + 게스트 진입

**Status:** ready-for-agent

- [x] 재설정 요청 시 인증코드가 메일로 오고, 코드 만료·재발송·실패 제한이 가입과 같이 적용된다
- [x] 코드로 새 비밀번호를 설정하면 기존 모든 토큰이 무효화된다
- [x] 현재 비밀번호를 확인해야 새 비밀번호로 바꿀 수 있고, 변경 후 다른 기기의 토큰이 무효화된다
- [x] 닉네임을 바꿀 수 있고 규칙·중복 검사가 가입과 같다
- [x] 프로필 화면에서 닉네임·비밀번호 변경이 동작한다
- [x] REST API 경계 테스트로 검증된다
