# 20: 경기 이벤트 알림

**What to build:** 회원이 팔로우한 팀·선수의 경기 시작, 득점/이벤트, 경기 종료/결과, 라인업 발표 알림을 설정에 맞게 받고, 알림을 누르면 해당 경기 상세로 이동한다.

**Blocked by:** 13 라이브 스코어 갱신, 18 알림 설정 (종류별 + 대상별 토글, 동기화), 19 푸시 기반: 기기 등록 + 발송 모듈

**Status:** ready-for-agent

- [x] 경기 시작·득점/이벤트·종료/결과·라인업 발표를 라이브 갱신이 감지해 알림을 만든다
- [x] 팔로우한 팀 또는 선수와 관련된 경기만 대상이 된다
- [x] 꺼진 종류나 꺼진 대상에는 알림이 가지 않는다
- [x] 같은 이벤트는 한 회원에게 한 번만 보낸다(재감지·재시작 후에도)
- [x] 두 팀을 모두 팔로우한 경기도 알림은 한 번만 간다
- [x] 탈퇴 유예 중인 회원에게는 알림이 가지 않는다
- [x] 알림을 누르면 해당 경기 상세로 이동한다
- [x] 가짜 외부 API·푸시·시계로 위 동작이 REST API 경계 테스트에서 검증된다
