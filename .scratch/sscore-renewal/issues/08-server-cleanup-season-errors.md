# 08: 서버 정리: 오류 응답, 현재 시즌 자동 결정, 컨트롤러 정리

**What to build:** 서버가 오류를 공통 방식(상태 코드+메시지)으로 돌려주고, 시즌이 날짜로 자동 결정되며, 컨트롤러가 외부 API·비밀값을 직접 다루지 않는다. 사용자에게 보이는 기존 조회 동작은 바뀌지 않는다.

**Blocked by:** 01 Flyway 기준선 + API 테스트 틀

**Status:** ready-for-agent

- [ ] 공통 오류 응답(상태 코드+메시지)이 모든 컨트롤러에 적용되고 예외를 삼키거나 콘솔에만 찍는 곳이 없다
- [ ] 현재 시즌이 날짜 기준으로 자동 결정되고 코드에 고정된 2025가 없다
- [ ] 컨트롤러가 API 키나 RestTemplate을 직접 쓰지 않는다
- [ ] 파일명과 클래스명의 불일치, 잘못된 위치의 클래스가 정리된다
- [ ] 외부 축구 API 호출과 응답 해석이 한 모듈에 모이고, 예상 밖 응답이 와도 잘못된 데이터를 저장하지 않는다
- [ ] 기존 조회 API의 요청 경로와 응답 형태가 유지되거나 앱과 함께 바뀐다
- [ ] 정리 전후 동작이 REST API 경계 테스트로 동일함이 검증된다
