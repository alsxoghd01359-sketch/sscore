# 04: 로그인 + 로그인 유지 + 게스트 진입

**What to build:** 회원이 이메일과 비밀번호로 로그인하고, 앱을 다시 켜도 로그인이 유지된다. 게스트는 로그인 없이 메인에 들어가 조회하고, 개인화 기능을 누르면 로그인으로 안내받는다. 앱의 공통 네트워크 계층(Repository, 토큰 처리, 오류 안내)이 이 티켓에서 만들어진다.

**Blocked by:** 03 가입 + 이메일 인증코드, 02 앱 서버 주소 분리 + 템플릿 잔재 정리

**Status:** ready-for-agent

- [ ] 로그인 성공 시 액세스 토큰(30분)과 갱신 토큰(14일)이 발급되고 구조화된 응답을 받는다
- [ ] 실패 응답은 이메일/비밀번호 중 어느 쪽이 틀렸는지 구분하지 않는다
- [ ] 액세스 토큰이 만료되면 갱신 토큰으로 자동 갱신되고, 갱신 토큰도 만료되면 로그인으로 안내한다
- [ ] 로그아웃하면 이 기기의 토큰이 무효화된다
- [ ] 토큰이 앱의 암호화 저장소에 보관되고 앱 시작 시 저장된 로그인으로 바로 메인에 간다
- [ ] 저장된 로그인이 없으면 게스트로 메인에 들어가고 경기·순위·선수·팀·리그 조회가 된다
- [ ] 개인화 기능(팔로우·알림·프로필)을 누르면 로그인 화면으로 안내된다
- [ ] 네트워크 오류·로그인 만료·서버 오류가 일관된 메시지로 보이고 재시도할 수 있다
- [ ] 로그인·가입·갱신·로그아웃이 REST API 경계 테스트로 검증된다
