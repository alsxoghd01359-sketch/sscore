# 01: Flyway 기준선 + API 테스트 틀

**What to build:** 개발자가 어느 PC에서든 같은 DB 구조를 만들 수 있고, 백엔드 REST API 경계로 테스트를 쓸 수 있게 한다. 현재 DB 구조를 첫 기준선으로 잡고 이미 적재된 데이터는 그대로 보존한다. 외부 축구 API·메일·푸시·시계를 가짜로 바꿀 수 있는 테스트 틀을 만들고, 기존 경기 조회 동작 하나를 첫 테스트로 통과시킨다.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [x] 서버 시작 시 Flyway 마이그레이션이 실행되고 JPA 자동 생성은 검증 전용이다
- [x] 기준선 마이그레이션이 현재 로컬 DB 구조와 일치하며, 기존 데이터(경기·선수·통계 등)가 그대로 남는다
- [x] 엔티티와 DB 구조의 불일치(FK, 유일성, null 허용)가 기준선에서 정리되어 검증을 통과한다
- [x] Testcontainers MySQL 8 위에서 마이그레이션이 적용된 상태로 REST API 테스트가 실행된다
- [ ] 외부 축구 API, 메일 발송, 푸시 발송, 시계를 테스트에서 가짜로 교체할 수 있다 (축구 API·시계는 완료, 메일·푸시는 해당 기능이 생기는 03, 19번에서 같은 방식으로 추가)
- [x] 기존 경기 목록 조회가 테스트로 통과한다
- [x] 새 PC에서 빈 DB로 시작해도 마이그레이션만으로 구조가 만들어진다
