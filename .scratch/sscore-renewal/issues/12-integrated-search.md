# 12: 통합 검색

**What to build:** 사용자가 검색어 하나로 팀·선수·리그를 한 번에 검색하고, 종류별로 구분된 결과에서 상세 화면으로 이동한다.

**Blocked by:** 08 서버 정리, 04 로그인 + 로그인 유지 + 게스트 진입

**Status:** ready-for-agent

- [ ] 팀·선수·리그가 한 번의 검색으로 조회되고 결과에 종류가 표시된다
- [ ] 결과를 누르면 해당 팀/선수/리그 상세로 이동한다
- [ ] 한글·영문 이름 검색이 모두 동작한다(선수 2.5만 명 규모에서 허용 가능한 속도)
- [ ] 결과가 없을 때와 오류 시 안내가 보인다
- [ ] 앱 검색 화면이 ViewModel/Repository 구조로 옮겨진다
- [ ] REST API 경계 테스트로 종류별 검색이 검증된다
