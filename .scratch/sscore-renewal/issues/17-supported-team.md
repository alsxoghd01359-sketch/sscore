# 17: 응원 팀 지정 + 자동 팔로우

**What to build:** 회원이 프로필에서 응원 팀 하나를 지정하면 그 팀이 자동으로 팔로우되고, 순위표에서 강조된다. 응원 팀을 바꿔도 이전 팀의 팔로우는 남는다.

**Blocked by:** 16 팀·선수 팔로우 (동기화 포함), 09 리그 상세 + 순위표 정리

**Status:** ready-for-agent

- [ ] 프로필에서 응원 팀을 지정·변경할 수 있다
- [ ] 응원 팀을 지정하면 그 팀이 팔로우 목록에 포함된다
- [ ] 응원 팀을 바꿔도 이전 팀의 팔로우는 유지된다
- [ ] 순위표에서 응원 팀이 강조된다
- [ ] 응원 팀이 다른 기기에서도 복원된다
- [ ] REST API 경계 테스트로 검증된다
