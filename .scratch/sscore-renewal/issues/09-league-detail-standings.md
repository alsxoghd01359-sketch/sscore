# 09: 리그 상세 + 순위표 정리

**What to build:** 사용자가 리그 상세에서 순위·경기·선수 통계·팀 통계를 탭으로 보며, 기존과 같은 정보가 정리된 구조로 제공된다. 서버는 책임별 서비스로 나뉘고 앱 화면은 ViewModel/Repository를 통한다.

**Blocked by:** 08 서버 정리, 04 로그인 + 로그인 유지 + 게스트 진입
