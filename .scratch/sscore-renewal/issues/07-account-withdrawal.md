# 07: 회원 탈퇴 (30일 유예)

**What to build:** 회원이 비밀번호를 확인하고 탈퇴를 요청하면 즉시 모든 기기에서 로그인이 막히고, 30일 안에는 다시 로그인해 복구할 수 있으며, 유예가 끝나면 회원 데이터가 영구 삭제된다.

**Blocked by:** 04 로그인 + 로그인 유지 + 게스트 진입

**Status:** ready-for-agent

- [x] 비밀번호를 확인해야 탈퇴를 요청할 수 있다
- [x] 탈퇴 요청 즉시 회원이 탈퇴 유예 상태가 되고 모든 토큰이 무효화되어 로그인이 막힌다
- [x] 유예 30일 안에 복구하면 정상 회원으로 돌아온다(복구 방법은 앱에서 안내)
- [x] 유예 중인 이메일로 새로 가입하려 하면 복구 안내를 받는다
- [x] 유예가 지나면 스케줄러가 회원과 딸린 데이터(팔로우·알림 설정 등)를 영구 삭제한다
- [x] 삭제된 이메일로 다시 가입할 수 있다
- [x] 시계를 주입해 30일 경과를 REST API 경계 테스트로 검증한다
- [x] 프로필 화면에서 탈퇴가 동작한다
