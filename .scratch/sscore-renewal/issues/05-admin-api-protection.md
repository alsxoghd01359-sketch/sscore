# 05: 관리자 API 보호

**What to build:** 서비스 운영자가 데이터 적재·갱신·취소 같은 관리 기능을 ADMIN 권한으로만 호출할 수 있다. 외부인은 데이터를 바꾸거나 외부 API 호출 한도를 소진시킬 수 없다.

**Blocked by:** 04 로그인 + 로그인 유지 + 게스트 진입

**Status:** ready-for-agent

- [ ] 회원에 역할(일반/ADMIN)이 있다
- [ ] 모든 관리 기능은 ADMIN 토큰이 있어야 호출되고, 게스트·일반 회원은 거절된다
- [ ] 상태를 바꾸는 관리 기능은 조회 요청이 아닌 변경 요청(POST 등)이다
- [ ] 디버그용 원본 응답 주소가 제거된다
- [ ] 게스트의 조회 기능은 계속 인증 없이 동작한다
- [ ] ADMIN 계정을 만드는 방법이 문서화된다(환경 설정 또는 초기 계정)
- [ ] 권한별 접근 허용/거부가 REST API 경계 테스트로 검증된다
