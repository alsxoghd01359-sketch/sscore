# 16: 팀·선수 팔로우 (동기화 포함)

**What to build:** 회원이 팀과 선수를 팔로우하고 해제하며, 목록을 보고, 다른 기기에서 로그인해도 같은 팔로우가 복원된다. 게스트가 누르면 로그인으로 안내된다.

**Blocked by:** 04 로그인 + 로그인 유지 + 게스트 진입

**Status:** ready-for-agent

- [ ] 팀 상세·선수 상세에서 팔로우 여부가 보이고 바로 바꿀 수 있다
- [ ] 팔로우 목록 화면에서 팀과 선수를 모아 보고 해제할 수 있다
- [ ] 팔로우가 서버에 저장되고 다른 기기에서 로그인하면 그대로 복원된다
- [ ] 홈에서 팔로우한 팀의 경기를 쉽게 찾을 수 있다
- [ ] 게스트가 팔로우를 누르면 로그인 화면으로 안내된다
- [ ] 중복 팔로우가 생기지 않는다
- [ ] REST API 경계 테스트로 추가·해제·목록·복원이 검증된다
