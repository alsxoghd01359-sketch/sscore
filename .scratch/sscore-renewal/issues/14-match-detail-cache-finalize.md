# 14: 경기 상세 캐시 + 종료 확정본 저장

**What to build:** 진행 중 경기의 상세(타임라인·라인업·통계·선수 평점)가 짧게 캐시되어 많은 사용자가 봐도 외부 호출이 늘지 않고, 경기가 끝나면 확정본이 DB에 저장되어 이후에는 외부 호출 없이 제공된다.

**Blocked by:** 13 라이브 스코어 갱신

**Status:** ready-for-agent

- [ ] 진행 중 경기 상세는 짧은 시간 캐시되어 같은 경기를 반복 조회해도 외부 호출이 늘지 않는다
- [ ] 경기 종료를 감지하면 타임라인·라인업·통계·선수 평점의 확정본이 DB에 저장된다
- [ ] 확정본이 있는 경기는 외부 호출 없이 DB에서 제공된다
- [ ] 이미 종료된 과거 경기도 첫 조회 때 확정본이 저장된다
- [ ] 캐시·확정 로직이 가짜 외부 API로 REST API 경계 테스트에서 검증된다
