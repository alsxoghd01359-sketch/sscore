# 15: 경기 상세 화면 정리

**What to build:** 사용자가 경기 상세에서 타임라인·라인업(선수 평점 포함)·상세 통계·상대전적을 경기 전/후 상태에 맞는 탭으로 보며, 진행 중 경기는 화면이 보이는 동안 자동 갱신된다.

**Blocked by:** 14 경기 상세 캐시 + 종료 확정본 저장, 04 로그인 + 로그인 유지 + 게스트 진입

**Status:** ready-for-agent

- [ ] 경기 전에는 미리보기·라인업·순위·상대전적, 경기 후에는 정보·라인업·통계·상대전적 탭이 보인다
- [ ] 매치 타임라인이 시간순으로 득점·카드·교체를 보여 준다
- [ ] 라인업에 포메이션과 선수 평점(API-Football 값)이 표시되고 진행 중에는 갱신된다
- [ ] 상세 통계가 홈/원정 비교로 보인다
- [ ] 상대전적이 보인다
- [ ] 앱의 경기 상세 화면이 ViewModel/Repository 구조로 옮겨진다
- [ ] 로딩·오류·재시도 상태가 일관되게 보인다
